# SWLOR boot handler classification for hot reload: SWLOR.Game.Server only
# One line per handler of a boot script, in the order the registry runs them: class, then Namespace.Type.Method.
# Classes (BootReload): Rerun = the new build runs it again; BootOnly = never again after boot (a mixed handler is split into the two);
# NativeHook = installs a native hook; Retire = runs at shutdown and when a generation retires. UNCLASSIFIED fails EveryBootHandlerHasABootPhase.
# The rule and the reasons are in SWLOR.Game.Server/Readmes/MaintainabilityRefactorHotReload.md section 2.
# Regenerate (build first so the handlers are current): SWLOR_UPDATE_SNAPSHOTS=1 dotnet test SWLOR.Game.Server.Tests --no-build --filter "FullyQualifiedName~BootHandlerClassificationTests"   (PowerShell: $env:SWLOR_UPDATE_SNAPSHOTS='1'; dotnet test ...; Remove-Item Env:SWLOR_UPDATE_SNAPSHOTS)   (build SWLOR.Game.Server.Tests first so the generator sees your handler)
