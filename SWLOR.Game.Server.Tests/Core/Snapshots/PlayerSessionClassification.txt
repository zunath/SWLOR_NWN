# SWLOR login and logout handler classification for hot reload (P4-15): SWLOR.Game.Server only
# One block per handler of mod_enter and mod_exit, in the order the registry runs them: class, Namespace.Type.Method, the step a
# reload runs for each online player (Restore at activation, Quiesce at quiescence), then the reason.
# Classes (PlayerReload): Restore and LoginOnly for mod_enter, Quiesce and LogoutOnly for mod_exit. UNCLASSIFIED fails
# EveryLoginAndLogoutHandlerHasAPlayerSession. The rule is in SWLOR.Game.Server/Readmes/MaintainabilityRefactorHotReload.md (P4-15).
# Regenerate (build first so the handlers are current): SWLOR_UPDATE_SNAPSHOTS=1 dotnet test SWLOR.Game.Server.Tests --no-build --filter "FullyQualifiedName~PlayerSessionClassificationTests"   (PowerShell: $env:SWLOR_UPDATE_SNAPSHOTS='1'; dotnet test ...; Remove-Item Env:SWLOR_UPDATE_SNAPSHOTS)   (build SWLOR.Game.Server.Tests first so the generator sees your handler)
